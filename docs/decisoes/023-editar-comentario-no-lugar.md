# 023. Editar comentário no lugar

- **Data:** 2026-10
- **Status:** ativa

## Contexto

Etapa "Telas de edição". Registrada no antigo `docs/MEMORY.md`.

## Decisão

**Editar comentário no lugar:** o comentário vira caixa de texto no próprio card; uma tela só para isso seria exagero. O admin pode apagar qualquer comentário, mas editar só o autor, igual à API.

## Consequência

O porquê e o efeito foram registrados junto com a decisão, no texto acima.
